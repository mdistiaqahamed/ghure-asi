১. Gemini API key নিন: https://aistudio.google.com এ গিয়ে "Create API key"।
২. index.html ব্রাউজারে খুলুন, চ্যাট বট (🤖) খুলে উপরের 🔑 বাটনে চেপে key বসান। key শুধু আপনার ব্রাউজারে সেভ থাকে।
   অথবা index.html এ GEMINI_KEY='' এর ভেতরে key বসাতে পারেন (শুধু নিজের টেস্টের জন্য)।
৩. মডেলের নাম index.html এ GEMINI_MODEL এ আছে। error এলে AI Studio তে দেখে বর্তমান ফ্রি Flash মডেলের নাম বসান।

সতর্কতা: ওয়েবসাইট জনসমক্ষে দিলে key ফাইলে বসাবেন না, কারণ যে কেউ দেখে ফেলতে পারে।
পাবলিক সাইটের জন্য key সার্ভারে (যেমন Cloudflare Worker) রাখুন।
